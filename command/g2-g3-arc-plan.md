# G2/G3 圆弧运动实现计划

## 目标

为雕刻机补齐 GRBL 常用的 `G2` 顺时针圆弧和 `G3` 逆时针圆弧，使 LightBurn 输出的圆形、字母曲线和圆角能够被正确执行，并继续复用现有的 planner、junction、segment ring 与步进执行链路。

第一版采用“命令层计算圆弧、拆分为连续直线 block”的方案。planner 不直接生产圆弧脉冲，也不增加圆弧专用执行器。

## 设计结论

```text
G2/G3 G-code
    ↓
command_executor / motion parser
    ↓ 解析终点、I/J 或 R、平面、方向
圆弧几何模块
    ↓ 按弦误差和最大弦长细分
连续 G1 线段
    ↓
motion_submit
    ↓
planner 前瞻、junction、block 冻结
    ↓
stepper_prep → segment ring → timer/RMT
```

圆弧的几何计算属于 motion/command 层；planner 只接收已经确定的连续线段。这样可以保持现有运动执行链路不变，降低对已经稳定的暂停、恢复和脉冲输出的影响。

## 支持范围

第一版支持：

- `G2`：顺时针圆弧；
- `G3`：逆时针圆弧；
- 当前工作平面 `G17`：XY 平面；
- 终点使用绝对坐标或相对坐标；
- `I/J` 圆心偏移；
- `R` 半径格式；
- 圆弧中的 `F` 进给速度和 `S` 激光功率继承现有 modal 状态；
- 圆弧结束后更新解析器位置，并保证最后一个细分点精确落在目标终点。

后续再扩展：

- `G18`：XZ 平面；
- `G19`：YZ 平面；
- 原生圆弧 block；
- 更高效的整圆和大半径处理。

## 几何规则

### I/J 格式

在 `G17` 下：

- 圆心 `C = 起点 + (I, J)`；
- 半径为起点到圆心的距离；
- 终点必须与圆心距离近似相等；
- `G2` 和 `G3` 根据方向选择角度增量。

I/J 默认解释为相对圆心偏移，不受 `G90/G91` 终点模式影响，这与 GRBL 常用语义一致。

### R 格式

- `R > 0` 选择小于或等于 180° 的圆弧；
- `R < 0` 选择大于 180° 的圆弧；
- 当起点和终点重合时，`R` 格式拒绝，因为无法唯一确定圆弧；
- 同时出现 `R` 与 `I/J` 时拒绝，避免几何定义冲突。

### 整圆

起点和终点重合时，只允许 `I/J` 格式，并将角度增量设为完整一周。没有 `I/J` 或半径为零时返回圆弧参数错误。

## 细分策略

每个圆弧转换成若干连续直线 block。细分数量同时受以下条件约束：

1. 最大允许弦误差；
2. 最大单段弦长；
3. 单次命令允许生成的最大 block 数；
4. 坐标和步数范围。

建议第一版参数：

```text
最大弦误差：0.01 mm
最大弦长：1.0 mm
最少段数：整圆至少 16 段
单条圆弧最大段数：不超过 planner 可安全提交的范围
```

实际细分数量取几何误差和最大弦长要求中的较大值，并限制在安全上限内。最后一段不使用累计浮点角度作为终点，而是直接使用 G-code 目标坐标，避免累计误差。

## 速度与激光连续性

- 所有细分线段使用同一个 programmed feed；
- 线段之间不能人为插入停止点；
- 每个细分 block 都必须带有正确的方向向量和距离；
- planner 通过 junction 计算相邻弦段的连续入口/出口速度；
- 圆弧细分段的激光模式和功率继承原始 G2/G3 命令；
- 不在圆弧细分过程中调用独立的暂停、停止或激光开关流程；
- 命令完成应在所有细分 block 排入 planner 后返回，不能只提交部分圆弧并提前报告完成。

## 参数校验与错误

以下情况必须拒绝整条圆弧，且不能提交任何细分 block：

- 当前平面不是已支持的 `G17`；
- 缺少有效的终点或圆心定义；
- 同时使用 `R` 和 `I/J`；
- `I/J` 计算出的起点半径与终点半径误差超限；
- 半径为零或非有限数；
- `R` 无法构造有效圆；
- 计算出的细分数量超过上限；
- 细分后的目标坐标超出软限位或机器范围；
- planner 无法接受首个 block。

错误发生时，解析器位置、planner 位置和实际位置都不能被部分更新。

## 实施阶段

### 阶段一：解析接口与参数校验

阶段状态：代码已实现，等待实机验收。

1. 在 motion 请求中增加圆弧请求类型或圆弧专用提交接口；
2. 解析 `G2/G3`、终点、`I/J`、`R`、`F`、`S`；
3. 实现 `G17` 模态检查；
4. 完成 I/J、R、整圆和冲突参数校验；
5. 错误时保证无 planner 副作用。

验收标准：

- 合法圆弧可被识别；
- 非法参数返回稳定错误；
- 不产生任何脉冲和部分 block；
- 现有 `G0/G1` 行为不变。

### 阶段二：I/J 圆弧几何细分

1. 实现 XY 平面圆心、半径和角度计算；
2. 实现顺时针、逆时针角度展开；
3. 根据弦误差和最大弦长生成中间点；
4. 强制最后一个点使用精确目标坐标；
5. 将中间点提交为连续 motion block。

验收标准：

- 四分之一圆、半圆、整圆轨迹正确；
- G2/G3 方向相反且起终点一致；
- 实际终点误差不超过一个步距；
- 圆弧过程中无明显停顿、嘟嘟声或速度归零。

### 阶段三：R 半径格式

1. 根据起点、终点和半径计算两个候选圆心；
2. 按 `R` 正负和 G2/G3 方向选择正确圆心；
3. 处理 180°、近似整圆和短弦长边界；
4. 复用 I/J 格式的细分器。

验收标准：

- 正负 R 选择的弧段大小符合 GRBL 语义；
- 无效半径不会提交部分运动；
- R 格式与等价 I/J 格式轨迹一致。

### 阶段四：连续运动与 LightBurn 验证

1. 检查圆弧细分 block 的 junction 速度；
2. 检查圆弧与直线连接处的入口/出口速度；
3. 检查圆弧中的激光功率连续性；
4. 检查 `!`、`~`、`0x18` 在圆弧细分过程中仍符合现有语义；
5. 使用 LightBurn 生成的包含曲线字母、圆和圆角的文件实机雕刻。

验收标准：

- 圆弧和直线连接处不明显减速到零；
- 暂停、恢复不会重复或跳过细分段；
- Abort 后 planner、segment 和 prep 全部清空；
- LightBurn 能完成整件包含圆弧的雕刻任务。

## 不采用的方案

- 不在 timer/RMT ISR 中计算三角函数或生成圆弧；
- 不让 planner 直接理解并执行 G2/G3 脉冲；
- 不通过回放 G-code 实现暂停后的圆弧恢复；
- 不在圆弧每一小段之间强制速度归零；
- 不在第一版同时引入原生圆弧执行器和新的 segment 类型。

## 参考与边界

- 圆弧命令解析应对照 `D:\ray2-old` 的实际 G2/G3 行为；
- 几何细分属于 motion/command 层，planner 继续只负责 block 级规划；
- 第一版完成阶段二后即可覆盖常见 LightBurn XY 雕刻场景，再决定是否需要 XZ/YZ 和原生圆弧 block。
