# 圆弧连续供料与雕刻功率稳定性计划

## 问题背景

`G2/G3` 第一版将圆弧离散为连续直线 block，并一次性批量写入 planner。手动短圆弧可以产生预期轨迹，但完整 SD 雕刻文件出现以下现象：

- 电机出现周期性嘟嘟声；
- 实际运动速度显著低于 G-code 的 `F` 值；
- 使用 `M4` 的雕刻段到达预期路径附近却缺少可见痕迹。

这些现象不应归因于 RMT 引脚或脉冲外设。长直线已经验证通过，问题发生在圆弧被大量短线段离散后。

## 已确认的机制

```text
G2/G3
  -> 小弦长直线 block
  -> junction/加速度对每个短段约束实际速度
  -> M4 按 actual_speed / programmed_feed 缩放 S 功率
  -> 低速段功率降低，可能无可见雕刻痕迹
```

当前 `stepper_prep` 对 `M4` 使用实际 segment 速度相对 programmed feed 的比例缩放功率。这一语义本身正确，但短弦段使实际速度持续偏低，导致输出功率也持续偏低。

当前第一版还有一个供料限制：单条圆弧的全部细分 block 必须在同一时刻放入 32 深度 planner ring。SD 供料在可用空间不足时只能反复重试，无法像普通 G-code 流一样持续向下游补充圆弧后缀。

## 目标

1. 圆弧精度与机器步距、光斑和雕刻用途匹配，不以低于一个步距的几何误差换取大量短 block；
2. 圆弧执行期间 planner 和 segment ring 保持连续供料；
3. 保持现有 planner 的 junction、冻结 block、Feed Hold、Resume 与 Abort 语义；
4. `M4` 在真实速度降低时仍遵守动态功率语义，但不会因人为过细离散导致整体能量不足；
5. 不在 timer/RMT ISR 中计算圆弧几何，不重新引入直接脉冲生成路径。

## 设计原则

### 1. 几何误差必须服务于硬件分辨率

当前 XY 步距为 `0.0125 mm`。`0.01 mm` 的弦误差低于一个步距，不能转化为等比例的实际轨迹收益。

后续弦误差应作为机器参数或圆弧模块参数，初始候选范围为：

```text
弦误差：0.05 - 0.10 mm
最大弦长：2 - 5 mm
```

最终值必须以圆形轮廓、字母曲线、激光光斑和实际雕刻效果验收，不能只按浮点几何误差决定。

### 2. 圆弧必须是可续供的逻辑运动源

圆弧不能再要求“全部细分 block 一次性占满 planner”。它应保持自身的几何上下文：

- 原始起点、终点、圆心、半径、方向和总 sweep；
- 已生成的弦段序号与下一个点；
- F、S、M3/M4 模态；
- parser 提交位置与最终目标位置；
- 是否已完成全部细分。

当 planner 可用空间达到低水位时，圆弧展开器只生成后续有限数量 block。这样 planner 始终看到普通连续直线 block，而上游不需要等待整条圆弧获得完整容量。

### 3. G-code 的原子性必须保留

圆弧开始前必须完整校验全部几何条件和机器范围。通过校验后，可允许它分批生成 block，但不能把“供料暂时不足”变成 `error:motion-busy` 并要求主机重发同一条 G2/G3。

因此需要区分：

- 几何或坐标错误：立即拒绝，不改变 parser 状态；
- 已接受的圆弧：parser 只提交一次，圆弧上下文由内部供料器继续完成；
- 后续供料不足：内部等待 planner 容量，不能将原始 G-code 回退给 SD 或 UART。

## 职责边界

| 模块 | 新职责 | 不承担的职责 |
| --- | --- | --- |
| `command` | 解析 G2/G3，完成一次性几何校验，创建圆弧展开上下文 | 不直接操作 planner ring 或 STEP |
| `motion` | 将圆弧上下文转换为有限批次的线性 `MotionRequest` | 不决定 junction 和脉冲时序 |
| `planner` | 接收普通 block，按既有前瞻和冻结规则执行 | 不计算三角函数或保存 G-code 语义 |
| `sd` / `protocol` | 只提交原始 G-code，一次接受后不重发圆弧 | 不负责圆弧背压 |
| `stepper_prep` / `laser` | 继续使用实际速度、segment 和 M3/M4 语义 | 不修正圆弧几何 |

## 实施阶段

### 阶段一：测量并校准离散参数

阶段状态：代码已实现，等待实机验收。

当前首个实机候选值已设为弦误差 `0.05 mm`、最大弦长 `2 mm`；与先前
`0.01 mm / 1 mm` 的低于步距误差基线进行对比。

1. 为圆弧细分记录只读诊断：每条圆弧的半径、sweep、弦段数、最大弦长；
2. 使用小圆、大圆、字母曲线分别测试 `0.01/1 mm`、`0.05/2 mm`、`0.10/5 mm` 候选参数；
3. 记录 planner 队列、segment 队列、实际速度、M4 段功率和激光痕迹；
4. 固化一组符合步距与雕刻效果的默认参数。

验收标准：

- 圆弧轮廓不出现肉眼可见多边形；
- 短弦段数量显著下降；
- 连续曲线速度和 M4 出光明显稳定；
- 不改变 G0/G1 和现有直线雕刻结果。

### 阶段二：引入可续供圆弧上下文

1. 将当前“一次生成完整数组”的圆弧请求改为持久展开上下文；
2. 在 planner 具有低水位容量时生成固定上限的后续弦段；
3. 一条圆弧只允许一个活动展开器，保证 G-code 顺序；
4. 在最后一个弦段精确落到原始目标坐标；
5. 取消 `arc-too-complex` 作为正常大圆弧的容量限制，仅保留合理的安全总段数上限。

验收标准：

- 大于 32 段的圆弧和整圆可以执行；
- planner 不因等待下一批圆弧弦段而清空或进入 underflow；
- SD 文件不会因已接受圆弧返回 `motion-busy`；
- parser 位置只在整条圆弧被接受时更新一次。

### 阶段三：速度和 M4 能量验证

1. 对比 M3 固定功率与 M4 动态功率在相同圆弧上的实际痕迹；
2. 检查每段实际速度相对 programmed feed 的比例；
3. 调整离散参数和 junction 约束，使圆弧稳定速度接近合理的曲率速度；
4. 不为掩盖低速问题而取消 M4 的实际速度功率缩放。

验收标准：

- M4 圆弧在设计 S 值下留下连续可见痕迹；
- 不出现因 segment 启停导致的激光断续；
- M3/M4 的差异仍符合固定功率与动态功率的设计语义。

### 阶段四：完整作业回归

1. 使用包含直线、I/J 圆弧、R 圆弧、字母和闭合轮廓的 LightBurn 文件；
2. 分别验证 UART 流和 SD 作业；
3. 在圆弧内部验证 `!`、`~`、`0x18`；
4. 观察 `$POS/STATUS` 中 planner、segment、underflow、速度和激光状态。

验收标准：

- 无 task watchdog、stack overflow 或 position invalidation；
- 无周期性嘟嘟声、异常低速或明显多边形；
- 曲线和直线连接处连续出光；
- 暂停恢复不漏段、不重段，Abort 后完全清空执行状态。

## 不采用的方案

- 不通过降低 RMT 频率或改变 STEP 脉宽处理圆弧速度问题；
- 不关闭 M4 动态功率缩放来掩盖实际速度过低；
- 不把全部圆弧段直接预填进 segment ring；
- 不把圆弧三角函数计算放入 ISR；
- 不以扩大 planner ring 作为根本解决方案。
