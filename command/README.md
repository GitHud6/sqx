# G-code 命令模块

`command_executor` 将一条完整 G-code 行解析为事务性状态更新或 `MotionRequest`。
解析失败、软限位失败或 planner 拒绝时，不提交新的解析状态。

## 当前支持

- 模态：G0、G1、G2、G3、G20、G21、G90、G91、M3、M4、M5。
- 坐标与进给：X、Y、F、S；支持无空格词、分号注释和括号注释。
- 圆弧：支持 I/J 和 R 定义；按 0.05 mm 弦误差、2 mm 最大弦长离散，单条圆弧最多
  32 个运动请求。超出预算或几何非法会返回明确错误。
- 零位移模态/功率行不生成空运动 block。

## 边界

本模块不访问 GPIO、RMT、Timer 或 SD。它只生成请求，实际位置由 stepper 执行路径维护。
