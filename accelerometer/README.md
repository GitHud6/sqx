# 加速度计模块

`accelerometer` 是 LIS2DH12 的运动异常保护模块。它独立于 `stepper`：不参与
planner、profile、AMASS、Timer 或 RMT 的脉冲生成，也不用于振动补偿。

## 职责

- 仅在 planner 存在活动运动时采样 X/Y 原始加速度。
- 原始值连续 10 次超过 `500` 时，判定为异常机械加速度。
- 判定后禁止激光运动输出，并调用 `planner_reset()` 中止当前运动。

采样任务运行在非实时核心；检查周期为约 150 ms，确认样本之间间隔约 15 ms。阈值
`500` 来自产线大量测试，用于避免正常雕刻和常规机械振动误触发。

## 硬件边界

- 芯片：LIS2DH12
- I2C 地址：`0x19`
- SDA / SCL：GPIO38 / GPIO39
- INT1：GPIO40（当前只完成配置保留，采样使用后台 I2C 读取）

## 实现与验收

1. `driver/lis2dh12_driver` 负责 I2C 初始化、WHO_AM_I 校验、寄存器配置和 XYZ 原始读取。
   - 验收：启动日志确认地址、引脚与 WHO_AM_I=`0x33`。
2. `accelerometer` 负责非实时阈值确认和安全处置。
   - 验收：正常雕刻不误触发；持续超阈值时激光关闭、planner 复位且打印异常日志。

该模块不应被用作实时波形采样或闭环振动控制；这两类功能不得接入 Timer/RMT 热路径。
