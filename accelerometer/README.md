# 加速度安全监测模块

`accelerometer` 是独立于运动控制链的非实时安全监测模块。它在存在活动运动时读取传感器数据，对连续异常进行确认，并通过 `service` 请求安全中止。

## 职责

- 在驱动初始化完成后创建后台采样任务。
- 仅在 planner 存在待执行或正在执行的运动时检查运动加速度。
- 使用连续采样确认过滤瞬时机械振动与读取抖动。
- 确认异常后请求 `service` 进入安全中止，并记录任务级故障。

## 并发与安全边界

- 采样与确认运行在非实时任务上下文，不进入 Timer、RMT 或限位 ISR。
- 只提交安全中止请求，不直接清空 planner、停止定时器或改写 stepper 位置。
- 传感器初始化与底层寄存器访问属于 `driver`；任务状态与故障处置属于 `service`。
- 此模块不是闭环控制、振动补偿或实时波形采集路径。

## 修改步骤

1. 调整判定策略前，先区分单次瞬态、连续异常和传感器通信失败的处理语义。
2. 保持采样任务与运动 ISR 隔离，避免在热路径加入 I2C、日志或复杂计算。
3. 新增故障类型时，同步更新 `service` 的故障原因和协议可观察状态。
4. 修改驱动初始化依赖时，确认传感器不可用不会破坏基础运动链路。

## 验收标准

- 静止和正常运动不会误触发安全中止。
- 连续异常能够关闭运动输出并进入不可自动恢复的安全状态。
- 传感器读取不影响 segment 生成或脉冲时序。
- 初始化失败时，故障状态清晰且不会访问未初始化外设。
