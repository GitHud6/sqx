# 激光输出模块

`laser` 管理激光输出的安全许可和功率应用。它将 planner/stepper 携带的段功率映射到硬件驱动，并确保暂停、复位、归零和故障路径始终优先关闭输出。

## 职责

- 以安全关闭状态初始化和释放激光输出外设。
- 根据当前执行段的功率和执行标识更新输出，避免旧段事件覆盖新段状态。
- 维护运动输出许可，只有坐标与任务状态满足安全条件时才允许使能。
- 为任务结束、暂停、复位、归零和安全中止提供立即关闭接口。
- 连接 planner 执行事件与段级功率更新，不参与路径或速度计算。

## 并发与安全边界

- ISR 只应用已量化的段功率或执行安全关闭，不访问通信、文件和任务状态机。
- 功率策略属于 laser；任务是否可运行属于 `service`；脉冲时序属于 `stepper` 与 `driver`。
- 无论输入源来自何处，激光输出都必须服从同一许可与安全关闭路径。
- 不以收到命令的时刻直接改变运动段功率，避免通信时序影响执行结果。

## 修改步骤

1. 变更功率映射前，明确输入范围、关闭值和饱和策略。
2. 修改段事件关联时，检查执行标识能阻止过期事件重新打开输出。
3. 调整安全许可时，联测 `service` 的暂停、复位和故障路径以及 `homing` 的完成路径。
4. 新增 ISR 行为前，验证其不包含阻塞、动态分配或非 IRAM 安全访问。

## 验收标准

- 无运动许可、暂停、归零、复位和故障时输出保持关闭。
- 相邻 segment 的功率切换与实际执行边界一致。
- 旧执行事件不会影响当前任务的输出状态。
- 激光模块不修改 planner 速度、stepper 脉冲或机器位置。
