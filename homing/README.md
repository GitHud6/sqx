# 归零模块

`homing` 执行建立机床坐标基准的系统运动。它使用独立于普通 planner 的受控运动流程，结合限位反馈完成寻位、脱离和位置可信状态重建。

## 职责

- 在 planner 空闲、存储作业未运行且不存在其他归零任务时接受归零请求。
- 构建系统运动 segment，控制寻位、限位停止与脱离限位流程。
- 消费限位 ISR 的最小通知，在任务上下文判断归零成功、超时或中止。
- 成功后提交新的机器原点并同步解析器位置；失败、中止或异常后使位置失效。
- 在归零期间保持激光输出关闭，并根据成功结果恢复后续运动许可。

## 并发与安全边界

- 限位 ISR 只停止对应轴和唤醒归零任务，不执行完整状态机。
- 归零系统运动可直接使用 stepper 执行后端，但不复用普通 planner 队列。
- `service` 负责全局生命周期与恢复门控；`homing` 只负责坐标基准建立。
- 单轴诊断或测试运动不能被视为建立完整机器坐标。

## 修改步骤

1. 调整寻位流程前，明确每个阶段的限位前提、停止条件和超时语义。
2. 修改系统 segment 或轴停止逻辑时，联测 `driver` 的 ISR 回调与 `stepper` 位置更新。
3. 变更完成路径时，确保机器坐标和 `command` 解析器位置一起更新。
4. 变更失败路径时，确保激光保持关闭、位置失效且不会自动恢复运动。

## 验收标准

- 成功归零后位置变为可信，普通运动可以从新基准开始。
- 限位未触发、提前触发、超时或中止均不会保留可信位置。
- 归零期间普通作业与其他归零请求被正确拒绝。
- 限位 ISR 不包含文件访问、日志或复杂任务控制。
